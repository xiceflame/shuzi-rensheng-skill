# 示例（范例）

> **给 agent**：整理内容前先看这里的范例 —— 它告诉你「**好的产出长什么样**」。
> 格式规范见 `references/format-spec.md`；骨架见 `../assets/templates/`。

| 文件 | 对应页面类型 | 看什么 |
|---|---|---|
| `journal-example.md` | `wiki/journal/YYYY-MM-DD.md` | 怎么按**人/项目分组**；每条怎么带 `→链接` 和 `｜事实/计划/意义` |
| `person-example.md` | `wiki/people/<姓名>.md` | 背景 / 关键事实 / 关联 / **时间线（事件+意义）** / 记录目录 |
| `project-example.md` | `wiki/projects/<项目>.md` | 一句话 / 背景 / **当前进展** / 下一步 / 人员 / 素材 / 历史 |
| `monthly-example.md` | `wiki/monthly/YYYY-MM.md` | 汇总层怎么**带下钻链接**；怎么当「检索第一层」 |

> ⚠️ 这些是**虚构的例子**（人名项目名均为示意），只看**格式与颗粒度**，别照抄内容。

## 自检：你的产出够好吗

- [ ] 每条信息都带了 `→[[项目]]` 或 `→[[人]]` 或 `→[[当天]]`？
- [ ] 区分了 `｜**事实**` / `｜**计划**` / `｜**意义（解读）**` / `｜**待确认**`？
- [ ] 有具体数字（金额/日期/数量），而不是「聊了聊」？
- [ ] 过时信息挪到了「历史」，没写成「当前状态」？
- [ ] 是**提炼**，不是把聊天记录抄一遍？
