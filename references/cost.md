# 成本参考（怎么算、怎么省）

> **一句话**：这套系统的日常运行成本**很低**（一顿饭钱量级），
> 大头在**一次性历史回填**；而且大部分开销可以靠下面三条抓手压下去。
>
> ⚠️ 本文所有**数量与金额均为示意**（用来说明算法），请按 §二 的公式算你自己的。

---

## 一、成本从哪来

**只有「整理」这一步花钱**（需要 LLM）。其余全是本地免费计算：

| 环节 | 花钱？ |
|---|---|
| 解密数据库 / 图片解码 / 语音转码 | ❌ 本地计算 |
| 语音转写（本地 whisper） | ❌ 本地模型 |
| 向量嵌入（本地 Ollama） | ❌ 本地模型 |
| 向量嵌入（用 API） | ⭕ 少量（见 §五） |
| **提炼成笔记（LLM）** | ✅ **主要开销** |

## 二、成本公式（自己算）

### 2.1 三个计费项
几乎所有 LLM API 都按这三项计费：

```
成本 = 输入·缓存未命中 × 价₁  +  输入·缓存命中 × 价₂  +  输出 × 价₃
```

> **关键**：缓存命中的输入价通常是未命中的 **1/10 ~ 1/50**。
> 所以「复用同一份上下文」（系统提示 / 知识库规范 / 已读文件）能大幅省钱。

### 2.2 你的用量从哪来

| 任务 | 频次 | 单次输入 | 单次输出 |
|---|---|---|---|
| 摘要（写日记 + 更新人物页） | 每天 1–2 次 | 大（读当天全部会话） | 中 |
| 财务增量 | 每天 1–6 次 | 中 | 小 |
| 月汇总 | 每月 1 次 | 大（读整月日记） | 中 |
| 体检 / 想法复盘 | 每周 1 次 | 中 | 小 |

**估算法**：
```
月输入 token ≈ Σ(任务频次 × 单次输入)
月输出 token ≈ Σ(任务频次 × 单次输出)
```
> 实测经验：**输入里 80–95% 会命中缓存**（因为反复读同一份 CLAUDE.md / 上下文）。

### 2.3 峰谷价差（很多国内服务商都有）

以 **DeepSeek V4.1 Flash 官方价**（元 / 百万 tokens）**为例**：

| 计费项 | 空闲时段 | 高峰时段 |
|---|---|---|
| 输入 · 缓存命中 | 0.02 | 0.04 |
| 输入 · 缓存未命中 | 1.0 | 2.0 |
| 输出 | 4.0 | 8.0 |

- **高峰**＝周一至周五 **9:00–12:00、14:00–18:00**（北京时间）
- **其余时间（含周末、晚间）＝ 空闲，价格减半**

> ✅ **把定时任务排在空闲时段** 是最省力的一招（见 §四）。
> 其它服务商（智谱/通义/月之暗面等）也有类似机制或低价档，**用自己的价目表替换上表即可**。

## 三、量级感（示意，非真实数据）

> 下面用**假设的中等使用强度**演示（每天 2 次摘要 + 每天 4 次财务 + 每周 1 次汇总）：

| 项 | 量级 | 空闲价 | 高峰价 |
|---|---|---|---|
| 日常维持（每月） | 输入命中 ~百 M、未命中 ~十 M、输出 ~几 M | **几十元/月** | 翻倍 |
| 单次摘要 | — | **< 1 元** | 翻倍 |
| 单次月汇总 | — | **< 1 元** | 翻倍 |

**结论**：
- **日常维持**：**几十元/月**（一顿饭钱），且任务若排在空闲时段可再省一半
- **一次性历史回填**：**几百元**（把过去一两年的聊天全整理一遍）→ 这是最大的一笔
- **增量附件**：每月几十份 ≈ **几元**

> ⚠️ 历史回填**只做一次**（或按需做近 N 个月），不是每月都花。

## 四、三条降本抓手

### ① 任务排在空闲时段
定时任务**避开工作日 9–12 / 14–18 点**。
本方案的默认调度（早 8:07 / 晚 21:07、周汇总上午）**已经避开了高峰**。

### ② 最大化缓存命中
- 复用同一份**系统提示 + 知识库规范（CLAUDE.md）+ 上下文**
- 别每次重新组织 prompt 结构（变了就不命中）
- **本方案的 `engine/tasks/*.md` 设计就是为此**：任务定义固定，只变输入数据

### ③ 附件先本地抽文本 + 去重（**最有效**）
- PDF/Office 先**本地抽文本**（免费），再交给 LLM —— 别让 LLM 读二进制
- **去重**：同一份文件被转发多次只处理一次
- 效果：直接砍掉「未命中输入 + 输出」两块（也就是成本大头）

## 五、哪些环节可以用 API、多少钱

| 环节 | 本地（免费） | 用 API（有成本） |
|---|---|---|
| 语音转写 | whisper（要装 GB 级模型） | ASR 按**音频分钟**计费，通常 **几元/小时音频** |
| 向量嵌入 | Ollama + 本地模型（要 ~GB 模型） | 按 **token** 计费；**万条消息 ≈ 几毛~几元**（一次性） |
| 整理 | 本地小模型（质量差） | **主要开销**，见上 |

> **建议**：日常用 API（省环境），大批量一次性任务（如全量嵌入）可用本地免费跑。
