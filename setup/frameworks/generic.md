# 适配：通用（未识别的框架）

> 没识别出你是什么框架。没关系——**这套系统的关键约束是「不绑框架」**。

## 你需要自己确认三件事

1. **怎么读写文件？**
   只要你能读写 `<vault>/` 下的 Markdown，就能做整理任务。

2. **怎么跑命令？**
   系统定时（launchd/cron/schtasks）会调 `engine/run.sh`；
   你需要确认 `bash` 可用、`python3` 可用。

3. **怎么提醒用户？**
   配 `engine/notify.sh` 的渠道（飞书/企业微信/系统通知），或让用户自己看文件。

## 兜底路径

若上面任一项你做不到 → 让用户用 **`engine/run.sh <任务> --engine manual`**：
脚本会把 prompt 打印出来，用户复制给任意 AI，再把结果贴回 vault。
**系统其余部分（采集/解密/转写/建索引）全是纯脚本，照常自动跑。**
